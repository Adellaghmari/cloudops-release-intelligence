Portfolio project

CloudOps Release Intelligence

Change. Risk. Impact. Recovery.

A deterministic release intelligence console that connects deployment evidence to human decision support after “deployed”—not an AI assistant, not a generic CI dashboard.

What problem it solves

Teams often know that a release shipped before they know whether it is safe to keep, widen, or roll back. CloudOps persists release and operational evidence, runs explainable analysis, and surfaces policy and recovery readiness in one inspectable timeline.

What I built

End-to-end portfolio system

Angular SPA, Go API and worker on AWS Lambda, event-driven analysis pipeline, Terraform-managed infrastructure, GitHub Actions with OIDC, and OPA/Rego policy gates—designed for low idle cost and truthful evidence labeling.

Live project evidence vs synthetic demo data

Northstar Commerce scenarios and releases are SYNTHETIC DEMO DATA. They exercise the real analysis engines but do not represent a real employer, production company, or customer traffic.

This repository’s CloudOps pipeline and deployment evidence is LIVE PROJECT DATA when labeled as such in the UI—generated from this project’s own AWS deployment and signed workflow paths, not invented releases.

Every evidence surface in the console preserves its source label.
